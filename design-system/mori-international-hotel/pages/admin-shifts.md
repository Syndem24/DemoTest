# Admin Shifts — page override

> Overrides master for `/AdminShifts`.

## Layout
- Full width of `.hotel-main` (no narrow left column).
- **Bento** for Live / Gain / Ops above the fold.
- **Toolbar** actions (Start / Refresh / Save / End) in the hero.
- **Accordion** for start note + history (collapsed by default for history).
- **Note cards** + **modal editor** for rooms / guests / offers / gain / closing.

## UX rules
- Progressive disclosure: show summaries first; detail one click away.
- Keep Mori navy / teal / white only.
- Prefer density over long vertical stacks; avoid sacrificing Start → notes → End flow.
